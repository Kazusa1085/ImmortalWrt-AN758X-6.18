# ImmortalWrt for VSOL V2902A-S (AN7583)

This fork adds support for the **VSOL V2902A-S** (Airoha AN7583, UBI layout) on top of [naoki66/ImmortalWrt-for-Gemtek-brightspeed](https://github.com/naoki66/ImmortalWrt-for-Gemtek-brightspeed).

- Kernel: **6.18.60**
- Device profile: `vsol_v2902a-s-ubi`
- Management address: `http://192.168.1.1`
- TerminalPlus (ShellBox): **1.1**

The maintained, more detailed documentation is the Chinese [README.md](README.md). It covers hardware, implemented adaptations, build instructions, flashing warnings and current limitations.

Release assets: [GitHub Releases](https://github.com/Kazusa1085/ImmortalWrt-AN758X-6.18/releases)
